## 📌 Overview

The **Heart Disease Risk Prediction Dashboard** is an interactive Machine Learning web application built using Streamlit.

This system predicts the likelihood of heart disease based on key clinical and lifestyle indicators, providing real-time risk assessment and model insights through an intuitive dashboard interface.

The project demonstrates the complete ML lifecycle:
- Data preprocessing
- Model training
- Performance evaluation
- Interactive UI development
- Cloud deployment

---

## 🚀 Key Features

- Real-time heart disease risk prediction  
- Interactive clinical input controls  
- Probability-based risk assessment  
- Feature importance visualization  
- Confusion matrix for model evaluation  
- Clean, professional dashboard interface  
- Fully deployed on Streamlit Cloud  

---

## 🧠 Machine Learning Model

- **Algorithm Used:** Logistic Regression  
- **Evaluation Metric:** Accuracy Score  
- **Train-Test Split:** 80% Training / 20% Testing  

### Clinical Features Used:
- Gender  
- Age  
- Education Level  
- Smoking Status  
- Cigarettes Per Day  
- Blood Pressure Medication  
- Stroke History  
- Hypertension  
- Diabetes  
- Total Cholesterol  
- Systolic Blood Pressure  
- Diastolic Blood Pressure  
- BMI  
- Heart Rate  
- Glucose Level

## ⚙ Installation & Local Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/YOUR_USERNAME/heart-disease-risk-prediction-dashboard.git
cd heart-disease-risk-prediction-dashboard
```

### 2️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run the application

```
streamlit run app.py
```

---

## 🌍 Deployment

This application is deployed using Streamlit Cloud.

To deploy:
1. Push code to GitHub
2. Connect repository to Streamlit Cloud
3. Select `app.py`
4. Ensure `requirements.txt` is included
